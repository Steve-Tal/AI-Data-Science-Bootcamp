## Purpose

This repository contains my learning journey as I prepare for Year 4 of the BSc (Hons) AI & Data Science degree at Glasgow Caledonian University.

The aim of this bootcamp is to build a strong understanding of software development, Python, data science, machine learning, cloud technologies, databases, visualisation and GIS before beginning my honours project.

This repository will grow throughout the bootcamp and will include exercises, mini-projects, notes and practical work.
